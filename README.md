# Aboomdanz Brasil - Site

**A Matrix Espiritual: O Segredo de 5% que Deixou a Sobrevivência para Viver a Abundância Infinita**

## 🌟 Sobre Este Projeto

Aboomdanz é uma plataforma dedicada ao despertar espiritual, reprogramação mental e ativação da abundância infinita. Este repositório contém o site oficial com conteúdo transformador e ferramentas de ativação.

## 📄 Páginas Disponíveis

- **Página Inicial** (`index.html`) - Introdução à Matrix Espiritual
- **Portal Aboomdanz** (`portal.html`) - Espaço de transmutação energética
- **Biblioteca** (`biblioteca.html`) - Acervo de conhecimentos
- **Redes Sociais** (`redes-sociais.html`) - Conexão comunitária

## 🚀 Como Acessar

### Via GitHub Pages
O site está hospedado gratuitamente em GitHub Pages. Acesse:
```
https://aboomdanz.github.io/site-br/
```

### Localmente
1. Clone o repositório:
```bash
git clone https://github.com/aboomdanz/site-br.git
cd site-br
```

2. Abra qualquer página HTML em seu navegador

2. Selecione **Main** como source branch
3. Deixe a pasta como **/ (root)**
4. Salve as configurações
